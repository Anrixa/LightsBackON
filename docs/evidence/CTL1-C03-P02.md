## What this phase closes

The C03 host source defines six authorized switch intents. The base Alder scene already provides `SW_JW_BREAKER` and the original C03 overlay provides `SW_CROSSFEED`, `SW_BEACON`, and `SW_ROOF_BREAKER`, but **`SW_ACCESS_LIGHT` and `SW_ROOF_FEED` were missing physical interaction markers**. A player in the C03 preview could not select those switches by gaze/physical position although the headless reference solution used them.

- Add authored centimeter positions for the two missing interactive controls; retain existing C01 scene/world and all canonical contract electricity/timing untouched.
- Validate *all* host-authorized C03 switch identifiers against physically placed C01+C03 markers before adding any C03 preview geometry. Invalid or duplicate controls abort setup without adding partial preview markers.
- Add original, non-colliding switch plates and world labels at the six authorized markers, with **actual host snapshot** switch state: ENABLED/DISABLED, TRIPPED/RESET or ISOLATED/CONNECTED. These labels never claim a consumer is powered and display UNKNOWN when an expected host field is absent.
- Preserve the existing host-only `toggle_switch`, reach/raycast validation, grid protection, stable ladder access, unsaved preview identity and all C01 save isolation rules. Visuals never issue commands or mutate the grid.
