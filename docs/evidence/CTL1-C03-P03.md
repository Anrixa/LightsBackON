## Confirmed finding: inactive inherited switch candidates

The C03 source has **six** host-authorized switches but the underlying C01 Alder scene also supplies `SW_JE_BREAKER` and `SW_SIGN`. The C03 adapter's `targets()` previously exposed any inherited switch marker to its first-person target selector. Those two controls had no authorized C03 action, so they could compete for the reticle and appear aimable while doing nothing. The session now derives the active switch IDs from the **selected contract's loaded switch definition**. Foreign switches no longer appear in candidate selection, report zero interaction radius, or expose an entity position. The host still owns command validation; an unsolicited foreign switch command must fail without grid mutation. The original C01 controls remain active in C01.

## Landing safety improvement

P01 checked destination capsule clearance alone. An obstacle-free arrival in mid-air could therefore pass a local preview check. The P03 gate additionally checks for real floor support using a downward physics ray from the capsule foot and a walkable upward normal (at least 0.7). Both authored ladder destinations must be collision-clear and supported; an empty unsupported destination fails. The host must still admit `use_ladder` **before** any local transfer.
