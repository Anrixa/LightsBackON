## Reproduced contract-specific defect and correction

C04 P01 exposed `R_JE_TRUNK` through street-level `PANEL_JE` in `OfflineSession._repair_targets`, but the host physical range callback obtained `entity_position("R_JE_TRUNK")` through the old C01 `TRUNK_JE` basement work marker. The scene UI could therefore invite repair at the JE cabinet while the host rejected the same repair ID for lack of range.

`OfflineSession._work_marker_for(repair)` now resolves both UI planning and host distance/occlusion positions through one contract-specific function:

- C04 `R_JE_TRUNK` resolves to `PANEL_JE`.
- C01/C03 `R_JE_TRUNK` keeps its historical `TRUNK_JE` position.
- All other repairs retain their authored panel location.

This does not modify the C01 save schema, C03 ladder/route logic, grid, repair state machine, source contract definitions or gameplay authority. Commands remain subject to the live scene's physics ray and SessionHost admission.
