## Implementation

1. Each authored `WindowLight` marker has an independent original-procedural glass material. The existing per-building authoritative dark/temporary/grid target now fades through a staggered, monotone pane cascade rather than switching every window in lockstep.
2. Staged transitions are bounded. A new host state cancels and rebases from the **actual rendered** pane and lamp energies; changing Reduce Flashes while a fade is running also snapshots every pane. The setting continues to select the existing longer transition duration and does not touch camera aim or movement.
3. Existing Alder Street `Label3D` building signs gain an independent, text-and-symbol supply line: `[-] NO POWER`, `[~] TEMPORARY POWER`, `[+] GRID POWER`. The line changes only when the host-derived supply root changes, **before** the cosmetic fade completes. An animation never promotes itself to a powered gameplay state.
4. The flood remains tied to the authoritative pump-drain latch. No new gameplay guidance, hidden-fault answers, audio assets, third-party art, telemetry or binaries were added.
5. Integration regressions in `tests/integration/test_DS04_power_cues.gd` exercise real C01 host recovery and authority invariants, staged multi-pane output, sudden loss of supply, and interrupted reduced-flash transitions.
