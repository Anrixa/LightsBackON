## Proved-by-inspection UX defects and implementation

1. The live accessibility scale controls used a fixed `HBoxContainer`; long localized text had no layout escape. Replaced it with a wrapping flow row. When pressing Scale Down reaches the 80% limit or Scale Up reaches 150%, the formerly focused disabled button now transfers focus to its enabled counterpart, avoiding a dead D-pad selection.
2. The main menu's unwrapped, fixed 46px title ignored viewport design scale. The title and eyebrow now wrap and the theme/heading scales according to the viewport. The existing menu scroll and focus-following behavior remain in place.
3. The S07 tablet header placed translated title text and the Network/Objectives tabs in a competing horizontal row. It now stacks title/sections with a wrapped tab row; the legend and action bar use independently wrapped rows, retaining a visible Close action on both tabs.
4. The Objectives page previously used an unscrollable VBox containing potentially six expanded lines and no controller focus. It now uses `FocusScroll` with D-pad/stick scrolling. Focus paths enter and leave the list, and scale/device rebuilds preserve the selected objective-scroll focus. Hidden map tools are excluded from the objective-page footer focus graph.
5. Evidence panel width is bounded to 44% of the screen's safe content area, preserving working space for the actual graph on 720p/narrow layouts.
