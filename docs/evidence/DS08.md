## What was built
- **Look** (`content/world/look_stormglass.json`, `scripts/world/street_look.gd`, `assets/shaders/stormglass_sky.gdshader`,
  `assets/shaders/stormglass_surface.gdshader`): static storm sky with cloud bands and a warm far-horizon glow, depth fog, filmic tonemap,
  glow on emissive windows and lamp lenses, cool diffuse moonlight (no shadow, see perf), procedural wet surfaces by role (brick, render,
  corrugated, concrete, painted metal, asphalt with puddles, paving, ground) with rain streaks and damp floors, a per-building palette so each
  service is a landmark, ground and routes re-drawn as 8 m tiles (the GLES3 per-object light limit; hiding the tiles made the frame 3.5 ms
  slower). Rain: camera-following GPU particles in world space (`scripts/world/rain_fx.gd`).
- **Diegetic dressing** (`content/world/alder_street_dressing.json`, `scripts/world/street_dressing.gd`): shop/house fascia signs with real
  names (ALDER COURT, Corner Market, The Lantern, ROWAN HOUSE, ALDER WORKS, PUMP HOUSE), flat supply plaques on each service (tablet name +
  icon + "NO POWER / TEMPORARY POWER / GRID POWER"), junction cabinets with plates (WEST JUNCTION JW, EAST JUNCTION JE), a storm-crew van with
  work light and beacon, 10 street lamps, kerbs, lane marks, the substation with poles and catenary wires, cable route markers and a skyline.
  All visual: no collision, no moved gameplay node (test below). The debug-ID billboards are hidden.
- **Host state only**: `RestorationPresentation` writes plaque text and icon from the host grid snapshot, like the window glow it already drove.
- **Lookdev scene** `scenes/lookdev/alder_lookdev.tscn`: the only place with fake states; every frame carries "LOOKDEV - FAKE STATE: ...
  (not host state)"; excluded from the public export preset; no shipping script or scene references it (test below).
- **Loading card** in the main menu (`show_loading_card`): see "Finding: cold shader cache".
- Tools: `tools/godot/capture_lookdev.gd` (state x view renders); `tools/godot/capture_hud.gd` now measures HUD contrast over the shipping
  look (the lookdev scene) instead of its own hand-made environment.

### Finding: cold shader cache (load stall)
Godot's GLES3 renderer stores compiled programs in `user://shader_cache`. On a cold cache (first launch, new driver, new build) the street's
materials compile on the first mission frame: 3.4 s on the Intel UHD, 4.7 s on the RTX 5090 (graybox: 0.2-0.7 s). A warm cache brings it to
0.2 s. ADR-017 allows no stall over 1 s *without a loading screen*, so the menu now shows a full-screen loading card ("Heading to Alder Street.
Preparing the street. The first launch can take a few seconds.") and presents it before the scene change; the card blocks a second press.
The stall itself is still there on a cold cache: a warm-up pass behind the card and fewer material variants are DS09 work (plan U7).

### Finding: content revision and checkpoints
The content revision is a hash over every file in `content/`, so look, dressing and string edits change it, and an offline checkpoint from the
previous revision is refused with `CONTENT_MISMATCH` (preserved, not deleted, ADR-008 behaviour). A player who updates a build mid-shift loses
the ability to continue that shift. Tests also use the PC's real user dir unless APPDATA is redirected, so a stale checkpoint fails V07 tests on
this PC; all runs here used fresh scratch dirs. No save data was deleted. Follow-up: key checkpoints on gameplay content only, or migrate
presentation-only revisions (save migration is on the owner's stop-and-ask list).
