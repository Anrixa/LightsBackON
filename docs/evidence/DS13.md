## Implementation

1. `scripts/ui/input_glyph.gd` (+ UID): an original procedural drawing component for keycaps, mouse clicks/wheel, neutral face buttons, shoulders/triggers, sticks, D-pad and an explicit Unbound fallback. Uses UI tokens and existing Noto Sans; no new art/media dependencies, no console brand assets. Reads the **live** `InputMap.action_get_events` and refreshes the semantic glyph automatically when remapped.
2. `scripts/ui/input_prompt.gd` (+ UID): reusable glyph-plus-localized-caption row that never accepts focus or mouse input.
3. `scripts/ui/field_hud.gd`: replaces the bracketed interaction prompt and tablet/ping action hints; carries the same semantic action/verb and inherits the project's responsive UI theme.
4. `scripts/ui/network_tablet.gd`: adds mouse/controller input glyphs for Close, Ping and Inspect, retaining existing request gate, focus flow, evidence scroll and actual button semantics. Objectives hides the ping glyph row along with its button.
5. `scripts/ui/onboarding_card.gd`: project-made step glyph strip and hint glyph, based on the actual tutorial action IDs; preserves descriptive localized instruction for text accessibility and does not add an input listener.
6. `scripts/ui/main_menu.gd`: removes the stale hard-coded WASD/E/A/Tab controls text and builds a wrapping six-action live glyph legend, switching on the same intentional-device tracker as gameplay, preserving scrolling/checkpoint logic and controller focus.
7. `content/ui/strings/en.json`: localized action captions for the menu and tablet; the original keys are not deleted (compatibility).
8. `tests/integration/test_DS13_input_glyphs.gd` (+ UID): thirteen automated regression cases for keyboard, mouse, controller variants, D-pad/triggers, unbound fallback, live remaps, noise filtering, active HUD, onboarding, menu, tablet focus and pseudo-locale/150% scale.
