Precision testing takes source-derived fixed host ticks; rapid testing spends a nonrefundable finite cell. Starting with an unmet dependency or too many active crews is refused. Premature confirmation aborts that checkpoint and is recoverable.

Neither resources nor completion may be spoofed through a client request. Rechecks never consume cells and precision can always finish without them.
- `operate_worksite` goes through the existing SessionHost admission, session, seq/dedupe, rate, shape, host range/optional scene physics LoS and canonical hash/revision. The client sends exactly one action for a source-bound target; no client positions, time, success, resources, task IDs or outcomes are accepted.
- Only explicit EXP012 sessions attach the new host authority and extraction gate; ordinary EXP03–EXP011 and production C01–C12 continue their old start signatures and rules. Five original atlas task IDs are bound to EXP012, but **restoration task 5 is not a pre-extraction prerequisite** (it is only completed by extraction). The optional discovery requires real previously-observed optional evidence and never blocks certification.
- First-person experimental worksite stations, decision and method controls and HUD, plus both Windows export memberships.

## Important content-quality ceiling

This implementation supplies **200 different source-bound worksite cases** and two graph routes per case, but it **does not yet prove 200 independently bespoke level-designs**. The current mechanical foundation uses eight domain graph families combined with region-specific finite resources and source-specific service evidence/timings. Further EXP012 batches must enlarge the set of truly hand-authored site-specific puzzles, alternate approaches, recoveries, authored worksite geometry and narrative consequences before the original 200 genuinely differentiated level-quality goal can be called fulfilled. Do not inflate coverage from identifiers or renamed interactions.
