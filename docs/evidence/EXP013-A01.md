## Implementation

- Adds 40 **individually authored** intervention scripts for existing levels `LV_041` through `LV_080`, covering REG_06–REG_10: Dust Foundry, River Silt, Lock Gates, Falls Spray, and Station Platform storms. Actual names, climate/risk and original task IDs are source-locked to the atlas.
- Every new case has its own named objective and local failure stakes; four distinct operational actions; different priority and resilience routes; three independently addressable station targets with a distinct, source-provided offset plan.
- New tranche: 40 sites, 80 operating routes, 320 sequential steps per pair of routes, 120 new targets. **Cumulative scripted coverage across A02 + EXP013 is now 80 sites; 120 locations still have only EXP012 A01's family graph.** Do not claim 200 genuinely finished bespoke levels.
- The previously built five *real* host operation modes (hold, bounded pulse, spaced sample, dual-station handoff, trim-and-settle balance) are reused intentionally. This tranche is differentiated in authored targets, ordered operations, dependencies, time windows and rollback consequences, **not an assertion of 40 novel engine primitives**.
- Uses the existing `operate_worksite` transport, host-side timing, player/session/sequence/dedupe, range and optional physics LoS. No untrusted client time, source ID or verdict is admitted.
- New `enable_site_exp013` opt-in argument is additive. A02's 40-site book, session hashes, outputs and behavior remain unaffected; LV_081–LV_200 still have no authored overlay. New source is independently audited and receives a distinct `EXP013_` source-hash namespace and `site_exp013` host snapshot.
- For the 40 new sites, source-provided centimeter offsets place three markers relative to the original west panel, spur panel and west repair anchor; **this does not demonstrate human-accessible or collision-safe 3D spatial layout**.
- Existing host strategy binding, failure/recovery, extraction interlock and interaction/HUD presenter are extended without creating a new unguarded ingress.
- Windows public/internal export presets both carry the second JSON book.
