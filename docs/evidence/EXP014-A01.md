2. Builds three station-specific noncolliding 3D control assemblies. Builds both authored source-route circuits between the actual source-bound host target positions. Every operation line retains its mode, action, target and support-target evidence metadata.

No new host command, time source, network ingress, collateral collision, physics blocker, task ID, save migration or economy behavior.
4. `tests/integration/test_EXP014_site_composition.gd`: audits/builds the full 200-site source catalog and 400 procedural routes, checks 3D source-to-target linkage, confirms no collision objects, negative tampering cases, live actual host fault/recovery transitions, and spot-checks actual runtime positions at all five source tranche boundaries and endings.
5. `tools/validate_exp014_composition.py` and `tests/python/test_exp014_composition.py`: regression metrics **do not count cosmetic renaming or timer changes as distinct mechanical puzzle structures**. These results motivate the next actual-mechanics expansion instead of claiming completion from naming alone.
6. `tools/run_tests.sh`: runs the independent EXP014 source/topology audit on Linux and Windows; the established test runner also discovers the new Godot/Python integration and mutation tests.
