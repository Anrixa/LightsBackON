## Content and code delivered
- `scripts/world/expedition_regional_facilities.gd`: **25 authored source-risk-bound facility families**, not 25 color-only variants. Each region defines four distinct 3D form types, a region-specific environmental clue arrangement, an original-setting risk signature and a palette tone. A site's existing category changes spatial form arrangement; its immutable task-marker positions select a safe facility slot and an evidence-bearing source task.
- `scripts/world/expedition_graybox.gd`: adds one composed facility package to the **selected** existing 52×52m EXP02 preview, without changing host authorizations or the underlying original ground collider.
- Each package consists of 4 purposefully shaped, non-physics facility assemblies and a source-specific hazard evidence vignette (plus nearest-task visual bearing). Geometry uses mesh-only boxes/cylinders and 3D labels, with **no** CollisionShape3D, CollisionObject3D, Area3D or navigation system; interactions, damage and route outcomes are not generated by presentation nodes.
- Geometry candidate placement is deterministic and checked against the original three landmark envelopes, exact five source task markers, tile bounds and a **2.4m static edge-to-marker stand-off**. This is not a capsule sweep, slope/visibility validation, line-of-sight certification or player/controller playtest.
- `tools/validate_exp014_regions.py`: independent Python review of all 25 source risks, 200 plans and 1,000 original task IDs; mirrors the static placement math without relying on visual labels. It rejects duplicated actual facility forms, reused environmental cues, forged region/level/task IDs, region-to-location risk splices and slot/marker conflicts.
- `tests/python/test_exp014_regions.py` and `tests/integration/test_EXP014_A03_regional_facilities.gd`: 25-region/200-site coverage, evidence-bearing, graphical scene construction, preservation of the old 5 markers and collision boundary, source mutation rejection and fail-closed negative cases.
- `tools/run_tests.sh`: registers the new source audit for Linux and Windows.
