## What was implemented

- **25 authored environmental evidence triads:** each existing atlas region has three different risk-specific observable cues, containment references and verification references. In total **75 unique source-linked environmental readouts**, using five distinct schematic instrument families (depth, conductivity, mechanical, structure, weather). These are *game-facing interpretations*, **not real-life safety instructions**.
- **Source-aware 200-site attachment:** `expedition_environment_feedback.gd` links the A03 facility geometry, original site location and region, the risk, the five original task identifiers and the EXP012/EXP013 source case. Three companion visual evidence stations are placed inside the existing A03 patch. The spatial position is category-sensitive, and every evidence station points back to an immutable source task.
- **Actual host observation:** `expedition_mission_stage.gd` attaches these readouts only after the matching source case is available. An existing stage reads the original intervention and subsequent A02 contingency snapshots and updates evidence colors and captions for pending/active/fault/verified. A foreign level ID, unknown route, out-of-bounds stage or unqualified source fails closed.
- **No gameplay authority added:** A04 never changes host state, task objectives, rewards, stock, network commands or recovery; it creates only `Node3D`, `MeshInstance3D` and `Label3D` scene elements. It has no collision body, `Area3D`, navigation region, timer or alternate player ingress.
- **Audit:** `tools/validate_exp014_feedback.py` independently checks 25 region profiles, 75 nonreused cues and all 200 original A02 source case identities against the original 1,000 task IDs, rejecting risk, region and task splices. Python mutation tests and all-site Godot scene/host-feedback tests are registered in the complete test runner.

## Meaningful scope / remaining limitations

A04 makes real, already implemented host progression and fault consequences *legible inside the 25 different regional environments*. It does **not** introduce 25 new host gameplay mechanics, new tasks, 200 fully hand-modeled site assets or fully playable geometry. The earlier A02 gameplay-condition diversity and 1,000 authored source task IDs remain unchanged. Do not count visuals alone as mechanically unique encounters.
