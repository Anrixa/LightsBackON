## Implemented source/headless behavior

- **25 explicitly region-authored behavioral approach profiles** bind facility access target roles, investigation order, live upstream guard, evidence protocol and risk-specific operational recommendation. A new independent source validator scores behavioral signatures with names, signs, colors and timer values intentionally excluded. Five actual evidence protocols are implemented: `paired`, `double`, `triangulate`, `timed`, `isolate`. The 25 profiles map to all 200 exact source cases and 1,000 unchanged task IDs.
- **Host-owned facility approach:** The caller chooses `guarded` (four host ticks to establish access) or `urgent` (one host tick, but additional evidence/mitigation liabilities). Both start at a source-pinned original SC target, not a client-provided coordinate. A source-specific host precondition must hold before access is granted.
- **Investigation alters information progressively:** An accepted first reading exposes the source's actual risk and live upstream guard; a second independent accepted reading exposes the evidence protocol; only completing the full two/three-step investigation reveals the recommended operating route. Evidence unlocks only from host actions at correct source stations, with required witness spacing and bounded expiry. Recovery invalidates previously observed intelligence. Missing, premature or foreign station actions cannot complete a stage.
- **Real operational choice:** The player explicitly commits `priority` or `resilience` after investigation. A risky/urgent or nonrecommended priority route requires an extra authenticated mitigation and witness settling; resilience requires a stabilizing witness and settling. The service locks the accepted decision, and the existing worksite route cannot be selected before reconnaissance completes or to an inconsistent strategy. Existing EXP012/13 interventions and EXP014 A02 contingencies remain authoritative after this preflight.
- **Fault and recovery:** Host-owned upstream support loss, evidence expiry and urgent exposure expiry set a fault, invalidate the plan, and require a source-pinned `recover` at the original recovery target. Recovery restarts the investigation; no client success, time, reserve balance, task marker, or fabricated host verdict is accepted.
- **Geometry connects to mechanics:** Both approach choices are shown as distinct non-colliding corridor diagrams ending at the original SC markers; selecting an approach changes visibility based on the actual host snapshot. Source engineering only: these mesh ribbons do **not** prove reach, path feasibility, safe traversal, collision, sightline or accessibility.
- **Compatibility:** The new behavior is opt-in (`enable_site_approach`), requires the A02 contingency layer, uses only the existing `operate_worksite` authenticated/range-checked entry point, and adds a distinct content revision. The previous ten opt-in flags, all original 12 contracts, old source books, rewards, production saves and networking remain untouched.
