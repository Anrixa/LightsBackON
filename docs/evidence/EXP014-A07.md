## Implemented

1. **Source-locked five-family environmental hazard engine:** depth/water ingress, conductivity/insulation, mechanical/interlock, structure/clearance, weather/surge. A07 binds A05 investigated source, A06 operational consequences and A02 contingency identities; the host compares original level/location/region/risk, 5 immutable task IDs and original three SC_* targets.
2. **Noncosmetic procedural diversity:** 5 distinct ordered mitigation graphs, with different station roles, independent upstream host guards, witness spacing, and stabilization. The Python audit ignores action names, signage and clock-only variance in its canonical structural signature.
3. **Real operational trade-offs:** engineered control consumes finite host-owned site material; temporary bypass preserves material but creates residual liability, faster exposure escalation and a second authenticated final cleanup step. A06 managed-outage status accelerates this hazard exposure. Neither mode changes production earned rewards or deployed inventory.
4. **Host-driven escalation and recovery:** bounded host-tick pressure rises during mitigation/continued exposure. Actual upstream guard loss or an exposure threshold faults the hazard and blocks the worksite. Recovery is source-station-gated, requires genuine upstream support, consumes no client clock/success flags, does not refund spent materials or erase liabilities, and restarts mitigation.
5. **Worksite interlocks:** hazard containment must be verified before the chosen authored worksite strategy can proceed. The original site intervention and A02 contingency still run unmodified. Their actual success unlocks source-driven post-restoration checks; A07 completion is then required for extraction.
6. **HUD and command orchestration:** the existing first-person mission stage uses J to choose engineered vs temporary control; E sends the next host-requested action at the existing SC markers. Exposure, pressure, materials, fault, recovery and next step read from host snapshots. No physics, collision, navigation or new network/RPC path is created.
7. **Opt-in compatibility:** new enable_site_hazards requires A06; all earlier sessions remain opt-out and preserve their content revisions, original contracts, original saves, earned credits, and network authority.
