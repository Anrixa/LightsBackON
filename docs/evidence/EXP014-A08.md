## Actual implementation

- Source file: `scenes/expeditions/site_investigations_exp014_a08.json`, **200 exact site IDs**, each pinned to the A02 source level/location/region/risk/puzzle identity, 5 immutable source job IDs, 3 existing SC station IDs, and authored worksite action identities.
- Each site contains a **forensic** instrument-led 6-proof DAG and an alternative **field** 7-proof DAG. Two initial proofs become available in parallel; source prerequisites control later convergences. The field path works without consumable instrument charges but adds operational liability; the forensic path consumes 1–3 host-owned kit charges.
- The evidence proof types, station choices, guard predicates, dependency edges, and resource costs are explicitly serialized for every case. The independent audit **ignores text, action naming, site IDs and dwell ticks** when computing structural uniqueness. It requires 200 distinct source-free graphs **for each of two routes** and connected, acyclic evidence dependencies; 400 graph cases in all. Composite structural signatures do not imply 400 completely different primitive mechanics or 200 physically certified maps.
- Runtime `scripts/gameplay/expedition_investigation_chains.gd`: source identity/graph validation, host-bounded kit stock, independent witness stabilization ticks, real host upstream guard checks, non-linear currently available action frontier, explicit forensic/field selection, failure on stale observations or lost hazard authority, authenticated SC_C recovery with **no kit refund**, and separate final host certification.
- New `enable_site_puzzles` depends on A07 and leaves older experiment modes unchanged. The investigation begins only from A07 host-confirmed containment, **before** authored worksite intervention. While unsolved, host-side A01 worksite operation and extraction are blocked; the original A05 route cannot be changed by puzzle commands.
- Existing SessionHost transport/peer/sequence/dedupe/rate/range and optional physics visibility remain the only action ingress. A08 does not introduce a remote command schema, fake client evidence, new collision objects, physical route changes, production saves or rewards.
- The expedition HUD reads the host evidence frontier and shows discovered source actions, selected path, remaining kit, liabilities and recovery state. **P** selects forensic/field path; **O** cycles concurrently available proofs; existing interact key submits at the requested SC station.
