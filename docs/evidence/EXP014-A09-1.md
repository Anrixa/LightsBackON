## Real structural-diversity rule

`tools/validate_exp014_networks.py` derives exact canonical **unlabeled rooted-tree signatures** by recursively sorting each node's child signatures. It deliberately disregards site IDs, name strings, network notes, risk prose, capacities, edge names, clock values, numerical padding and node relabeling. All 25 manually selected primary-feed trees must be mutually nonisomorphic; capacities or cosmetically altered feeder labels alone cannot pass. Report **25 distinct primary-tree shapes**, not 25 fully independent network behavior engines.

The independent validator refuses source splices, hazard/risk drift, missing levels, mutations of the original 1,000 jobs, EXP05 fork/OR-join prerequisite drift, unsafe standby states, loops, duplicate edges, foreign receipt strategy targets, invalid capacity type, and accidental assertion of runtime enablement.
