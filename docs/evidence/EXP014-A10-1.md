# EXP014 A10.1 — Consolidated cross-system source oracle

## Authority and scope

This phase is an **independent source design/evidence audit** across the real
`atlas.json`, `campaign_routes.json`, A02 contingency book, A08 investigation
DAGs, and A09 region/feeder book. Parent A09.5 is CI-green at exact head
`91064b67158656a5af45b524a4d977dd970a4a46`, [run 44880853089](https://github.com/Anrixa/LightsBackON/actions/runs/44880853089).

The new `tools/validate_exp014_a10.py` does **not** generate replacement
levels, mutate original C01–C12 rules, change EXP04 receipts/field-points,
revise EXP05 OR-join requirements or alter a production save. It builds
machine-readable evidence in `build/exp014-a10-1/source-audit.json`
when run through `tools/run_tests.sh`.

## Required invariants

- 25 actual region records, 200 locations/levels, 1,000 original
  `JOB_NNN_1..5` IDs and 200 `FIND_NNN` IDs, preserving optional fourth task,
  zero new credits and original task scoring authority.
- Every region's eight authoritative site IDs join its atlas locations,
  investigation, contingency and campaign records; risk and source stations
  must match. No renamed book rows or duplicate IDs are accepted.
- Distinguish mechanical structures using investigation node kind, station,
  dependency DAG, guard, cost, contingency guard/failure/station topology and
  task mechanic; **exclude** narrative copy, action titles, timing and palette.
  200 structural site signatures and both 200-way investigation signatures
  must survive identity-free collision detection.
- Verify 25 exact unlabeled protected-feeder tree shapes. Upstream A09 validator
  independently verifies all 175 protected feeder edges and 50 standby ties.
- Explore 50 **abstract source-level** original EXP05 OR-join paths: a
  resilience-first branch using sites 1→2→4→5→7→8 and a critical-first
  branch using sites 1→3→4→6→7→8, each across all 25 regions.
  Every first/second join requires an actually completed predecessor; the
  critical/resilience source receipt must be in the selected branch. The
  source oracle evaluates feeder parent readiness before each dispatch and
  records a managed-outage fallback where the original branch is dark rather
  than inventing power capacity or forcing the other branch.
- Reject mutation tests: duplicate/missing sites, task/collectible splices,
  optional-task promotion, contradictory source risk, altered OR-join rules,
  investigation proof cycles and decorative/unused evidence, replacement
  mechanical graphs with renamed text/timers, and strategy proof that is absent
  from the selected branch.

## Coverage classification

The **50 source-level branch simulations are not 50 real SessionHost replays**.
The A10.2 phase will send authenticated host command envelopes across the
real scene/runtime and execute negative faults/receipts as independent tests.
The source fingerprint only proves that static authored *source
structures* are nonidentical; it does **not** prove 200 distinct, navigable
play experiences, player/controller reach, correct physics, solver accuracy or
balanced difficulty.

## Qualification and release holds

Source changes remain draft and stacked on A09.5. Require new exact-head
Linux + Windows CI, QA57 exported smoke, separate independent review,
ancestor-ordered controlled merges and merged-main CI before promotion.
Regional decisions are still **process-local**, not durable across restart.
Human/controller playability, real physical collisions/routes, hardware/GPU,
Steam two-peer, production credits/saves, final art, and release all remain
explicitly **HOLD**.
