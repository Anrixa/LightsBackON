## Source and eligibility
Stacked on **A10.1** draft PR #220 at exact passing commit `d0e482fc29a852ed79a6bf61f65580d644ef1a45`, Linux/Windows CI [run 44885075348](https://github.com/Anrixa/LightsBackON/actions/runs/44885075348).

This phase adds **real SessionHost message-envelope** coverage through `Runtime.receive(peer_id, PackedByteArray)` with isolated `user://` EXP04 profiles. Unlike the A10.1 Python route oracle, these probes invoke actual Godot host membership, session, sequence/dedupe, rate, entity range, source worksite authority and regional state machines. ## Replays
- **50 authenticated branch sessions:** both `critical_first` and `resilience_first` for each of 25 real regions, launched at the original first OR-join (slot 4) after preserving an EXP05-reachable earlier-region spine, locally persisted EXP04 source-valid root and route receipts.
- Each host receives a **foreign-peer** attempt, then a valid `operate_worksite` regional strategy request, a duplicate sequence (must not drain reserve twice), a forged board target, an extraction hold until regional preparation, then a valid `regional_managed` preparation. The unused alternate EXP05 fork must remain accessible.
- **12 multi-dispatch branch continuations** across six spread-out regions and both strategies: after a separate source-valid EXP04 join receipt is persisted, the second real host dispatch opens the correct next regional site and reuses the same account/region regional object, reserve, prior choice and events; the new site requires independent host preparation. Each second host has its own fresh command sequence.
- **Host-wire switching and transfer** for the first regional graph: isolate a normal feeder, engage original standby tie, reject make-before-break reset, release tie, safely reset, refuse reserve-anchor recharge with no restored supply. Preserve finite reserve consumption and no premature task receipts.
- **Receipt rollback** after a valid continued dispatch: write a structurally consistent but revoked prior proof to isolated EXP04 profile, then verify the next real dispatch refuses to attach to the already live network, without wiping live decision events.

Test names, assertions and explicit per-region progress are in
`tests/integration/test_EXP014_A10_2_host_scenarios.gd`.
The existing recursive Godot headless suite picks up the script automatically.
`tests/run_tests.gd` reports pass/fail/assertion counts under both Linux and Windows CI.

## Evidence classification and limitations
These are host-authoritative **source/headless** replays, **not** 50 physical
walkthroughs or a live multiplayer test. Test-only EXP04 receipts are generated
from immutable atlas definitions to exercise previously persisted legitimate
campaign state; these test receipts are not invented as actual completed player
missions and never enter production accounts.

Protected electrical topology is a deterministic state-machine model, **not**
a real power-flow, short-circuit, overload or safety engineering solver.
The A09 regional context remains **process-local**; successful reuse between two
Godot runtime objects does not certify survival across an app restart.

This run does not automatically demonstrate completed A08 nonlinear puzzle
playthroughs, full mission extraction or end-to-end player receipts.
Those are separately gated by established EXP08/A08/EXP03 host regressions
and future A10 qualification.
