## A10.4 committed implementation

- `tools/qualify_exp014_a10.py`: read-only, deterministic, fail-closed authority gate. Compares the immutable full 12-contract Git subtree with its independently recorded A10.3 tree OID; protects legacy credits, EXP04 ledger, EXP05 OR-join route source, offline SaveService, both atlas books and original SessionHost by pinned Git object IDs. Also checks protected working-tree cleanliness to prevent committed-tree evidence from hiding local edits. No unrelated paths are inspected, cleaned or deleted.
- Executes the original A10.1 cross-system source oracle and requires 25 regions, 200 locations, 200 levels, exactly 1,000 task IDs, 200 original lore IDs, 200 independent A08 graphs per route, 25 regional mechanical topologies, 50 original OR-join abstract scenarios and 300 source dispatch visits.
- Independently hashes the combined A08 investigation DAG and A02 contingency
  station-role graph for **each of the 200 sites** after normalizing level-
  specific IDs (`SC_NNN_A` etc.), excluding cosmetic source-action names,
  labels, site titles and timing/window values. A mechanical copy with
  all IDs and prose changed must still collide and fail the qualification.
  Three additional Python mutation tests prove this normalization.
- Inventories the nine uniquely named A10.2 and A10.3 required Godot regression methods and tracked `.gd.uid` files. **Presence is not execution**; execution is proved only by the full GitHub-hosted headless tests, not by the inventory.
- Runs automatically on both platforms from `tools/run_tests.sh`, writes `build/exp014-a10-4/source-gate.json`; CI also uploads a retained Linux source-gate artifact and includes Windows qualification JSON with its Windows build. Artifact uploads preserve available failure-side evidence without implying qualification; no GitHub API, credential or production save is required.
- Windows CI adds a gate after the existing QA57 release EXE/PCK export and smoke. It checks nonempty `LightsBackOn.exe`/`.pck`, verifies the source-pinned `git_commit`, clean build manifest and packaged manifest byte equality, and checks the **same build ID on the actual exported executable's headless boot log**. Emits SHA256 hashes, sizes and a strictly headless qualification status into `build/exp014-a10-4/windows-export-gate.json`, which is uploaded with the Windows artifacts.
- `tests/python/test_exp014_a10_qualification.py`: mutation-based regressions for protected contract/credit/save drift, missing or duplicate host tests, wrong exported source commit, altered packaged manifest, misleading boot ID, missing binary and incomplete evidence arguments.
