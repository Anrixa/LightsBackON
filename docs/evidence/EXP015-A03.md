The **original EXP05 restoration branch** changes the actual starting electrical state:

|---|---:|---:|

| `resilience_first` | 0 / 25 | 12 / 25 |

These figures are derived from the original A09 source tree and source-valid EXP04 test fixture receipts; they **are not 50 physically played routes or utility-grid measurements**.

New opt-in host runtime `scripts/gameplay/expedition_regional_finales.gd` offers these authenticated original worksite-board operations:

1. **`finale_assess`** — require authentic A09 receipt-backed strategy; capture current critical energized condition and shelter supply-readiness.
2. **`finale_critical_verified` OR `finale_critical_contingency`** — energized critical service is verified only when genuinely energized. Where the source remains dark, explicitly document an unserved critical-service pressure, determined by one of five original regional risk classes. The contingency is modeled consequence **not fictitious power restoration**.
3. **`finale_buffer` OR `finale_managed`** — invoke the **actual A09 `prepare_site`** with its existing finite `reserve_pu`, network-supply predicate and resource/debt behavior. Buffer consumes 2 PU if shelter supply is dark, none if genuinely ready. Managed dark supply records 2 PU of regional debt and 2 local shelter pressure, without minting electricity. A source-invalid/insufficient-reserve operation does not advance the state.
4. **`finale_verify`** — check actual live A09 state: proper site preparation, open shelter standby tie, unaffected shelter/critical feeders, and an unchanged critical energized condition.
5. **`finale_signoff`** — close only after valid verification. A completed signature is checked dynamically; unsafe feeder state later revokes `closed()` without altering original saved receipts or credits.

Existing `SessionHost.receive` → `operate_worksite` is the *only* command ingress: peer, session, deduplication, sequence, rate, range and existing optional physics line-of-sight checks are preserved. No new regional RPC, client-provided fault proof, user-supplied target IDs, clocks or reward claims. The original A09 regional-board direct preparation operations and switching of **only the critical/shelter feeders and shelter standby tie** are blocked within this opted-in finale; unrelated regional controls remain available. The new authoritative host snapshot, task-board state and source-pinned `EXP015_A03_` wire content revision expose decisions and actual reserve/service consequences.
