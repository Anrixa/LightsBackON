## Authenticated host mechanics

Opt-in `enable_alternate_routes` requires original A09 regional
networking with host campaign authority. Global opt-in does not break A01,
A02, A03, A04 or A05 sites: only the exact 100 authored routes activate A07.
The original source worksite board remains the sole ingress; no new RPC,
entity, authority or production schema. Session ID, peer membership,
sequence/dedupe, rate limiting, range, and optional line-of-sight gate remain
unchanged.

Each A07 site records real pre-incident `supply_ready` and `energized`
facts, trips its original A09 primary feeder using the **server-source fault
signature**, exercises a role-specific branch, clears the original fault via
the source recovery procedure, opens any active standby transfer before the
original reset, and verifies the *actual* dynamic feeder/tie state.
`signed_off` is revoked again by a real new feeder isolation or region
dispatch change. The active site never gets a fabricated EXP04 receipt or
energized state from a client action.

For first-route-A cases, `route_rapid` requires the original live
upstream and source feeder capacity >=16 PU; others must use managed
containment. First-route-B critical priority requires an actual originally
ready upstream source, not the illusion of a completed health facility.
Both original first-route roles require the exact source risk containment
protocol before fault clearance.

For second-route-A, `route_buffer` calls original A09
`prepare_site("buffer")`; it spends 2 PU when the trip disables normal
supply. `route_managed` calls original A09 managed preparation/debt.
Second-route-B `route_transfer` calls original A09 `engage_tie`, spending
2 PU under the existing break-before-make and live-source checks;
`route_prepare` uses A09 original prepare; `route_release` opens that
same original standby before `route_reset`. Failed transfer is nondestructive
and leaves the exact managed-outage fallback available.

All direct `regional_isolate/reset` requests for the incident's source
feeder, and `regional_engage/release` for the source-bound tie, are
guarded against bypass in the opted-in board. Only the original selected
assets are reserved. Opted-out sessions retain their previous original
A09 content revision and gameplay behavior.
