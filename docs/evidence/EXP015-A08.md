## 50 original rejoin site designs and actual operational choices

A08 does not add new physical locations or task IDs. It binds **25 first
rejoins (slot 4)** and **25 second rejoins (slot 7)** to their existing
EXP05 regional A09 primary feeder, the actual choice between preceding
first or second alternate branches, source risk/protection, and (only on
second rejoins) the original future-finale normal feeder and standby tie.

### First rejoin (commerce; 25)

Requires the actual A01 first-junction incident certificate AND the A09
prepared-site fact. On assessment it checks original A07 route-A transport
or route-B critical-health feeder activity, not arbitrary player claims.
To attest a previous route the existing A09 event ledger must contain a
valid ordered original **trip feeder → clear source fault → safe feeder
reset** for the corresponding feeder, the route must have an original
EXP04 restoration receipt, and the current feeder must be healthy. An
unproved route remains a separately marked **managed-unverified** decision.
Rejoining work then trips its own ORIGINAL rejoin-site feeder with the
A09 source fault signature, applies an original critical-supply-priority
decision only when real upstream critical electricity is energized, or
documents a managed local pressure. The exact source risk-containment
protocol is required before verified fault clearance/reset and signoff.
No root/critical power is fabricated by choosing a label.

### Second rejoin (education; 25)

Requires the A02 second-junction fault cascade to be dynamically resolved
and its A09 site preparation intact. The same original feeder event
provenance distinguishes preceding waterworks route A, communications
route B, or unverified managed handoff. The new incident trips the actual
slot-7 primary feeder with the original fault signature.

It can **stage the real future-finale standby** only when the original
A09 feeder graph supplies an energized tie source, the future finale is
not already energized, no conflicting tie/fault is present, original
capacity permits transfer and 2PU real reserve is available. It isolates
the ORIGINAL finale primary feeder before closing the actual tie through
A09's break-before-make interlock. This consumes real finite regional
reserve; it cannot be portrayed as restored finale supply. A failed
eligibility check does not mutate the regional network and the managed
response remains available.

Safe completion requires source-risk containment, clearing the original
rejoin fault, releasing any actual temporary standby, resetting the
future finale normal feeder before its A02 proof is re-established, then
resetting the join feeder and dynamically rechecking all source facts.
Subsequent re-isolation or dispatch-context changes revoke A08 signoff.
A08 does NOT certify the original final site or any production mission
completion.
