regional cold roots to their 25 original final dispatches, along both original
first-route priorities and both original commissioning resource policies:

- 25 regions × 2 original branch orders × 2 resource policies =
  **100 authentic source-bound root-to-finale scenarios**.
- Original A09 `entry_survey` → dual original feeder isolation → chosen
  feeder release → region-specific risk containment → real buffer expenditure
  or managed service debt → second original feeder release → source signoff.
- Ephemeral EXP04 **test fixtures** for original sites then let the same
  network attach to its original finale. The 2 PU original resource cost or
  debt must persist unchanged across that dispatch. No restored power or
  production player reward is claimed by the fixture itself.
- The final original anchor must be an actual restored and energized site in
  the injected replay. Managed debt may then be retired with exactly 2 PU of
  original reserve; a prior 2 PU buffer commitment cannot be spent twice.
- A repeated settlement operation must be rejected with an identical
  immutable snapshot: no double-debit, phantom recharge or duplicated debt.
- 25 independent source geometry/identity hashes, original source task IDs,
  original feeders, risk class and original reserve anchor are independently
  checked in Python; mutation tests reject fabricated anchors, feeder IDs,
  reserve amounts and release claims.

A11 uses the existing A09 host transition and A10 debt retirement; it does
not invent an alternate accounting system or alter the C01–C12 campaigns.
