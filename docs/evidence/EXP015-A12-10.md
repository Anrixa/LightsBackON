# EXP015 A12.10 — All-Intent Stale Session Authority Fence

**Source parent:** EXP015 A12.9 draft PR #255, exact head
\`3bd45d94b56d2fa09fa61c06bd8eb5d597a97250\`.
A12.9 CI #802 was still RUNNING when this source-only phase was stacked.

## Specific source-authority gap

A12.9 blocks obsolete \`operate_worksite\` requests and extraction, but
SessionHost still processes other accepted original mission intents
(e.g. inspect, grid switching, collectible claims, repairs, equipment,
self-recovery and expedition devices) through the old dispatch after
a newer dispatch has acquired the same process-local regional source.
An admitted peer is not necessarily the current regional host owner.

## Implementation

- Reuse the existing EXP06 host intent guard, which SessionHost invokes
  **after** byte shape, peer admission, session identifier, authenticated
  sequence, deduplication and rate-limit validation, but **before**
  any grid, interaction, equipment, collectibles, mission or optional
  expedition services run.
- If a network-enabled SessionHost has an obsolete host-only A09
  dispatch epoch, reject all non-worksite/non-extraction commands with
  \`EXP015_A12_10_STALE_HOST_INTENT\`.
- Keep A12.9 \`EXP015_A12_9_STALE_HOST_DISPATCH\` for obsolete
  worksite and extraction; let original \`anchor_*\` worksite
  commands reach A12.6's \`ANCHOR_DISPATCH_CONTEXT_EXPIRED\` fence.
  This prevents breaking inherited source-error contracts.
- Current SessionHost action flow is unchanged; sessions without
  A09 regional network remain opt-out/unchanged.
- No new RPC, response-side authorization, credentials, save schema,
  synthetic electrical power, credits, restoration or rewards.

## Headless authenticated replay

- 25 real original regional finales, each with two distinct
  authenticated sequential SessionHost dispatches on the same
  account-owned original A09 regional network object.
- Former admitted principal attempts 14 previously recognized host
  intent families (including inspect, grid switching, collect_lore,
  recovery, device/fault/consequence/logistics/balance, repair,
  ladder/route, lock/release). All are denied at pre-effect guard.
- Worksite/extraction preserve A12.9 rejection; anchor preserves A12.6
  rejection. Wrong peer and wrong session are rejected earlier by
  the original SessionHost security checks.
- An exact duplicate stale command returns the previously refused
  receipt without side effects. Finite reserve, original feeder
  event ledger, source site state, service debt, dispatch epoch and
  reward queue remain unchanged after rejected commands.
- The current host remains able to execute the original legitimate
  \`regional_critical\` 2-PU finite reserve choice.
