# EXP015 A12.15 — Bind-Once Original Dispatch Guards and Cached-Reply Replay Fence

**Exact stacked parent:** A12.14 draft PR #260 commit `ad79a86abaf0e4c200ece14cb7597f1e3975d6e1`. Source-only **DRAFT / HOLD**. Its exact-head CI #817 remains a separate qualification requirement.

## Original inspected risk
The host's authenticated A09 dispatch-epoch check and EXP06 intent policy were installed through mutable `SessionHost` setup methods; a caller holding the obsolete host could clear/replace these callbacks after successor activation, restoring forbidden snapshot, tick or command authority. The original per-peer `receive` dedupe cache also returned its previous successful response to a former host after dispatch preemption, reporting historical success under obsolete authority even though no second source mutation occurred.

## Changes
- The original host-owned dispatch epoch and expedition intent guard are now bind-once when given a valid callable. Later invalid or permissive replacements are ignored.
- An originally bound callback that becomes invalid is denied, not silently treated as opt-out. Tick, snapshot, publish and canonical read use the shared fail-closed predicate.
- A peer/session/shape-validated cached duplicate on an obsolete regional owner returns `EXP015_A12_15_STALE_REPLAY`, never an earlier successful reply. Valid current-owner and original non-A09 idempotent retransmits retain their existing behavior.
- No RPC, client-provided epoch, reward issuance, reserve increase, credit, regional source configuration or production save change.

## Regression
A headless authenticated real-original 25-region replay accepts a legitimate original finite-reserve worksite operation, preempts the owner, attempts to disable/replace both epoch and intent guards, retries the cached accepted command, submits a fresh stale command, and verifies unchanged source reserve, old revision/hash and a working new host. A separate non-A09 LV_001 probe verifies an accepted legacy `inspect` still replays as an idempotent duplicate.
