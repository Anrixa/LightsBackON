# EXP015 A12.4 — Temporal Source-Revision Signoff

**Stacked parent:** EXP015 A12.3 draft PR #249, commit `b21ea8dbb14c30ad63b64f929ff9560e47547228`.
Source engineering only; PR remains draft pending exact-head qualification.

## Defect demonstrated and correction

A12.3 correctly revoked a signoff while an original feeder was isolated, but
implicitly restored the **same old signoff** if another host-owned operation
reset that feeder and electricity returned. An old verification could also be
accepted after an intervening trip/reset occurring before signoff.

A12.4 binds verification and closeout to a host-observed **source revision**.
The revision counts authentic append-only A09 network events on original
root-to-anchor feeder edges and any standby tie capable of supplying the same
original path. It does **not** trust a client-controlled epoch, power boolean,
timestamp, new RPC, or persisted synthetic receipt. In-flight source mutation
revokes verification; a signed outcome stays revoked even after power returns.
Requalification requires a fresh audit, a real source action, original regional
fault-clearance proof, actual reset, verification, and signoff. Unrelated feeder
events are excluded from the epoch.
