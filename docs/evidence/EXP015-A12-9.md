## Source defect

A12.6 fences an obsolete A12 anchor controller using the A09 host dispatch
epoch, but the same obsolete process-local SessionHost can still send an
authenticated, otherwise valid \`regional_critical\`, \`regional_buffer\`,
\`regional_isolate:<edge>\` or other worksite action through the shared
A09 network after a newer same-account dispatch has attached. Its
authenticated original peer does not mean it is the *current*
dispatch owner. Source checks on the anchor controller alone did not
protect the broader original regional worksite authority.

## Implemented correction

- On original A09 network acquisition, SessionHost binds the current
  host-owned process-local dispatch epoch. The binding is never
  client-supplied, persisted or serialized into the save schema.
- Obsolete sessions are rejected before the generic worksite or
  original network/controller dispatch. Error:
  \`EXP015_A12_9_STALE_HOST_DISPATCH\`.
- Existing A12 anchor-specific stale-controller error
  \`ANCHOR_DISPATCH_CONTEXT_EXPIRED\` remains unchanged; anchor commands
  continue to be fenced at their original controller.
- Explicit extraction guard rejects a stale campaign dispatch before
  any inherited mission-completion/admission decision.
- No new RPC, fake electrical source, restoration receipt, reserve
  credit, reward, or external persistence.
- A12 recovery-enabled content revision is \`EXP015_A12_9_\` with
  inherited source-revision assertions updated.

## Tests and real host replay

- 25 original finale regions, authenticated first and second
  SessionHost dispatch with shared original A09 account/region source.
- Obsolete original host attempts to select reserve strategy, spend
  buffer, recharge, isolate a true original off-path feeder and invoke
  older settlement/assurance/aftercare actions. All must fail
  before mutating original network state.
- Previously bound A12 anchor denial and extraction denial remain
  effective; dispatch epoch, source feeder events, reserve, debt and
  rewards do not change after denied actions.
- A fresh current SessionHost can still execute the legitimate
  original \`regional_critical\` source strategy and debit precisely
  two finite reserve PU. No broad feature disablement.
- Original root-entry -> original finale replay ensures stale root
  commissioning commands cannot mutate the new finale's network.
- All EXP04 fixture receipts are isolated source-test inputs, not
  gameplay or production restorations.
