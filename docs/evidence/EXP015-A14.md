**Stacked on** EXP015 A13 draft PR #264 exact head `550f00bc87c8cce99b38c4fe7966e60e946627de`.

Adds 25 real authenticated host-session/Godot replays for failed takeover after a legitimate original reserve expenditure:
- A current regional owner makes a valid finite-resource decision (2 PU), retaining the source snapshot and original dispatch epoch.
- A would-be successor supplies additional test-only EXP04 receipts and tries to install a partial, intentionally incomplete A01 controller; transactional startup must fail with `EXP015_SITE_NOT_AUTHORED`.
- Rollback must restore the **entire** previously spent canonical source state: reserve, committed event log, receipt-visible routing, owner epoch and current owner.
- Foreign peer, forged session, and duplicate authenticated commands must not charge reserve a second time; duplicate response works only while its original owner is current.
- Legitimate subsequent successor activation advances the epoch exactly once; both cached and fresh commands on the retired owner fail, while new snapshots remain available.
- No reward entitlement, human/controller, hardware, Steam two-peer, cross-process state persistence or production-save claim is made.
