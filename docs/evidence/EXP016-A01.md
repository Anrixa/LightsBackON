**Independent parent:** EXP014 A10.4 draft PR #223 at pinned `aa59bb8a3fa667f8d9379a2ce8f174fa2766878e`. **No EXP015 source dependency**; this track can run alongside the EXP015 A12.16–A15 CI stack.

Code: `tools/audit_exp016_mechanical_diversity.py`, run by inherited Linux+Windows `tools/run_tests.sh` and Python mutation tests.

For every one of the 200 authored levels, compares existing EXP014 A02 two-route contingency mechanics and A08 forensic/field investigation DAGs, normalizing away level IDs, source titles, station IDs, action text, and clocks. It reports which sites truly share a structure, which regions lack sufficient variety, branch differentiation, task-mechanic mixes and recoverable failure modes. It fails on missing levels, spliced task IDs or foreign region/source mappings. **Does not fabricate novelty** merely because 1000 jobs exist.

A generated `build/exp016-a01/mechanical-diversity.json` provides a machine-readable backlog of repeated mechanics for later A02–A05 remedial authoring. No original authoritative assets or task IDs are altered; EXP015 host runtime integration, physical game/controller, multiplayer, hardware, production economy/save and release remain held. CI results and true diversity numbers must be read from the run output, not assumed.
