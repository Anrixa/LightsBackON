# EXP016 A08 — Real host equipment selections and finite worksite reserve use

Stacked draft successor to A07 #277. Inherits original SessionHost-admitted five equipment types. A new opt-in equipment manifest for each of 200 source-bound cases pins the original EXP012 worksite reserve-cell budget and operation-specific required tools. Authenticated worksite commands `case_equip:<tool>` select only genuinely admitted tools at the existing source panel; every subsequent step checks matching host selection. Paid repair operations consume a finite original cell budget on accepted host action only, not on rejection. Python proves all 400 authored routes have sufficient original reserve. Invalid source pin, forged tool, wrong station, tool mismatch, exhausted reserve and optional legacy sessions stay fail-closed.

This is headless authority and mechanic testing; not certification of rendered tool geometry/animations, human input, GPU, Steam, production saves or economy. Existing campaign, jobs, rewards and RPC remain unchanged. CI and independent review pending; no merge/tag.
