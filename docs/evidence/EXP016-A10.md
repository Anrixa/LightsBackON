# EXP016 A10 — Source graph carried consequences and recoverable setbacks

Draft successor to EXP016 A09 #279. Implements **25 exact original EXP014 feeder graphs covering 200 sites** as a strictly host-only, account+region-scoped, process-local evidence/debt ledger. An accepted authenticated case completion records its original site, policy, incurred pressure and recoverable faults once; duplicate identical outcomes are idempotent and conflicting outcomes rejected. Pressure flows only along the original directed feeder graph to connected downstream sites, not by guessed level number. Follow-up advanced investigations must perform an authenticated, upstream-guarded debt-settlement operation before original rewards/completion can finalize. Distinct accounts do not share state; wrong region and false completion fail closed.

This is **not** a production save, original EXP015 regional authority replacement, cross-process durability, Steam network transaction, physical or human/controller certification. A10 opt-in requires an already authorized original regional campaign host and the complete EXP016 source stack. Exact-head Linux/Windows source/host tests and independent review pending; original 12 contracts/1,000 jobs/economy unchanged, no merge/tag.
