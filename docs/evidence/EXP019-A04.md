# EXP019 A04 — Source-host environmental barriers and recovery

## Architecture
All 200 worksites receive physically collidable, class-specific bypass barriers. Five existing region risk categories map to explicit lane IDs; distinct raised routes remain accessible during host-sourced closures. Grid trouble controls a separate physical route blockade. This layer is **read-only projection** of authenticated local host snapshots; it cannot generate synthetic hazard success, award rewards, or change the existing saves or original C01–C12 missions.

## A04 failure and correction
**Original exact-head GitHub Linux and Windows logs:** `exp019_environment_physics.gd:30` raised `Trying to assign an array of type "Array" to a variable of type "Array[int]"`. Godot 4.7 conditional arrays yield dynamic `Array` values even when they contain integer literals. The dynamic assignment threw for every worksite, causing the four stage/integration tests to fail downstream.

**Correction:** author a single `CLASS_LANES` mapping keyed by the five source risk classes. Validate each source lane index is an integer, in range, nonduplicated and does not block all elevated routes. Append indices individually to a freshly created `Array[int]`; never assign the untyped conditional result to a typed array.
