# EXP020 A05 — solo continuity, onboarding and safe restart

Esc opens a pause overlay without changing SceneTree.paused. The host tick
loop and player input are frozen while Resume, Retry Pending Reward Save,
Restart Current Dispatch, and Return to Atlas controls remain operable.
F2 toggles concise, host-progress-sensitive onboarding, never solutions.

The stage is already a single-player local SessionHost; "Continue Solo"
keeps that authenticated host. Restart safely starts a *new* local host
from the original level/account/region request; unbanked electrical
progress resets intentionally. It is **not** a midmission checkpoint
restore nor online host migration. Account-specific receipts and saved
scores are untouched.

Before any restart/return, the original Ledger.receive tries to persist
and acknowledge all pending host rewards. Save errors/unacknowledged
receipts prevent departure; the player can resume and retry without
losing already-completed progress. A failed host intent remains a
recoverable denial rather than an automatic repeated host command.

No C01–C12 save schema, source task, reward or release contract change.
Human/controller/hardware/release qualification remains held.
