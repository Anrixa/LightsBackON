# EXP021 A03 — host-powered effects and accessibility gates

- EXP017 A03 source luminaire nodes are reused, no additional OmniLight3D instances; existing host only dictates supply state.
- Validated canonical grid + host snapshots: all four consumers checked before mutation; restored glow requires host mission verification and all three essential supplied consumers. A later outage immediately darkens the scene, never an asynchronous delayed cosmetic state.
- Frame update is bounded monotonic interpolation (0.70 energy/s when reduced flashes, 1.50 otherwise), with **no pulse, strobe, procedural flash, camera shake or additional brightness authority**.
- Existing accessibility snapshot schema is consumed read-only and atomically validated at 80–150% UI scale. Stage supports a session-local `exp021_display_preferences` injection for integration; no profile migration or save writes. Measured WCAG contrast for restoration status palette is checked by Godot tests.
- Regression tests: source identities for 200 sites, actual scene lamp reuse, stale host/grid rejection, on/off/recovery, preference rejection and zero camera displacement.
- Physical accessibility/photo-sensitivity, controller, GPU capture, frame latency and release are **HOLD** pending actual measured evidence.
