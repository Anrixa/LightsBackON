The menu FPS spread in the exported build (540-2585) is wider than the editor run (1285-1319). It was not investigated: window focus and
startup shader compilation are possible causes, and none of it is a P95 measurement.

The exit-time "leaked RID / PagedAllocator" lines in the FPS runs come from `timeout` killing the process, not from the game.
`--print-fps` gives one-second averages, **not** P95 frame time. These numbers are an upper-bound sanity check on a high-end GPU and
satisfy no performance gate.
