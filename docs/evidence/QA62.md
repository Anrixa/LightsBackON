## Reproduced source defects

1. `MissionRoot._finish()` previously displayed Results without moving focus to its only menu button. Because `_unhandled_input()` returns for `_finished`, a controller player with no pointer had no guaranteed usable way to leave the completed mission.
2. Authoritative mission simulation still ticks while Network Tablet is visible. Completion during tablet use left the full-screen tablet open over Results, potentially retaining focus and obscuring the exit.
3. An externally delivered completion event while a pause/settings modal is visible could leave the prior modal and its focus above the result transition.

## Correction

- Name and focus the existing Results action after its score is populated; preserve the title, score, button and session logic.
- Set `_finished` before dismissing an open tablet so its `closed` signal cannot re-enable movement. Hide pause and accessibility panels, disable movement and expose the Results panel.
- Keep completion idempotent and world input inert behind the Results view.
