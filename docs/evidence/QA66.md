# QA66 — Preserve user map navigation across tablet rebuilds

- **Date:** 2026-11-06 UTC.
- **Starting main:** `6103a2daa268224b4cd031a72f02c02a9b03bbb8` (QA64 merged; QA65 is an independent branch touching different files).
- **Branch:** `task/QA66-preserve-tablet-map-view`.
- **Scope:** Network tablet presentation state only; no authoritative simulation, power/repair topology, save data, content revision, engine or Steam changes.

## Defect

The tablet rebuilt its TabletMap on device change, UI-scale change, live host update and Network/Objectives tab switching. Each new map started at zoom index 2 and default offset, so the viewport silently jumped while the player was reading evidence or navigating an enlarged layout. Focus was already preserved but the map context was not.

## Correction

Capture the last map's requested zoom index and pan offset before removing the old visual nodes. Apply both to the newly created map, including when returning from Objectives; the existing layout clamps zoom and offset to the current screen to keep nodes accessible. No permanent profile data or network commands are changed.
