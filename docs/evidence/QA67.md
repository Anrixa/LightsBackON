## Defects and correction

The network tablet's `on_reply` ignored all `ping` replies. Its full-screen overlay therefore hid the main gameplay acknowledgment and refusals for pings, leaving no accessible, contextual outcome for players. In addition, an asynchronous `inspect` reply could replace the selected node's evidence status after the player had moved to a different node, misrepresenting what was inspected.

Handle both `inspect` and `ping` replies, but only when the reply's envelope entity matches the current selected node or that node's meter panel. For pings, show an explicit accepted label or a localized refusal in the tablet evidence pane using **existing localization keys**. Preserve the host's permission and rate-limit decisions. A stale reply never changes the currently selected detail. No files under `content/` change: the checkpoint content revision is preserved.

## Automated coverage
