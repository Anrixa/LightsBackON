# QA68 — Preserve requested map zoom through viewport fit limits

- **Date:** 2026-11-06 UTC.
- **Base main:** `1abd5708fd7a194182b16160cbe8a8f981826300`.
- **Branch:** `task/QA68-preserve-requested-zoom`.
- **Scope:** tablet map presentation only; no gameplay authority, content revision, save schema or Steam change.

## Defect and correction

`TabletMap.set_zoom_index()` previously clamped the **requested** zoom to the current `_max_zoom_index`. At compact window sizes, a temporary fit limit permanently discarded a higher preference. The tablet zoom buttons also stepped from rendered `zoom_index`, which could be lower than the user's intent.

Store the requested index within the complete authored zoom range and cap only the effective rendered index. Zoom buttons step from requested zoom, allowing the map to return to the chosen level when layout constraints lift.

## Regression

`test_QA68_map_zoom_preference_survives_temporary_fit_limit` checks desired vs effective zoom under an artificial tight fit limit, a zoom-out action, and restoration of the fit budget. Existing QA66 map reflow test must remain green.
