# QA69 — Keep authoritative zone tracking and fall recovery under the tablet

- **Date:** 2026-11-06 UTC.
- **Starting main:** `668179d7819b354990345e306af61ca9f0bf8710`.
- **Branch:** `task/QA69-recover-while-tablet-open`.
- **Scope:** offline MissionRoot frame ordering only; no host rules, save schema, content revision, transport or Steam changes.

## Proven defect

The tablet does not pause host time or gravity, but `_physics_process` returned early before updating van-zone membership or checking the below-world recovery threshold. A player who fell while the full-screen tablet was visible could remain below the world and never run recovery; authority could also retain a stale van-zone flag. An invalid position must never be checkpointed.

## Correction

Keep UI world targeting disabled while tablet is open, but run zone synchronization and the existing host-authoritative `recover_self` path on every physics step. Recovery teleports first, then writes the corrected checkpoint and leaves the tablet modal in control.

## Regression

`test_QA69_tablet_fall_recovery_keeps_save_and_modal_safe` forces a below-world transform with the tablet open. It checks a fresh isolated checkpoint, valid recovered coordinates, zero velocity, synchronized host van-zone, and continued modal input suppression. Existing QA63 and QA64 tests cover adjacent invariants.
