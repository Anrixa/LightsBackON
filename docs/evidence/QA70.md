# QA70 — Clear feedback when closing a tablet and ignore hidden replies

- **Date:** 2026-11-06 UTC.
- **Starting main:** `668179d7819b354990345e306af61ca9f0bf8710`.
- **Branch:** `task/QA70-reset-tablet-feedback-on-close`.
- **Scope:** non-authoritative UI-only lifecycle. No protocol, save schema, content revision or Steam changes.

## Defect and correction

The tablet retains its last inspection/ping success or refusal across closes and reopens. An asynchronous reply delivered after closing also updates the hidden evidence view; reopening the same node can present stale feedback as the current visit.

Clear transient feedback on close and open; suppress reply presentation while the tablet is not visible. A current, visible reply still uses the existing selected-entity check (QA67). This is presentation filtering only; host commands and responses remain authoritative and unchanged.

## Automated regression

`test_QA70_tablet_feedback_is_cleared_and_hidden_replies_are_ignored` exercises visible outcome, close, delayed refusal while hidden, reopen, then new visible acknowledgment.
