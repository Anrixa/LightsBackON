# QA71 — Synchronize evidence and Ping navigation with selected tablet node

- **Date:** 2026-11-06 UTC.
- **Starting main:** `b8846196b54b638aab02af7c35a90f2f87d790c4`.
- **Branch:** `task/QA71-sync-tablet-focus-backlinks`.
- **Scope:** local controller focus graph only. No host authority, localization revision, save schema or Steam changes.

## Defect and correction

The tablet sets the evidence and Ping buttons' left-focus neighbors once, in `_link_focus()` during rebuild. Selecting a new map node updates the visible evidence but not these focus neighbors, so a controller player returning left from the detail panel or Ping jumps to an obsolete node. This contradicts the tablet's selected-node context.

After a valid node selection, update both focus neighbors to the newly selected map node. Preserve current selection, existing focus and all map actions. Invalid/stale node IDs are rejected without clearing the display.

## Test

`test_QA71_evidence_and_ping_left_focus_follow_current_selection` uses a real tablet fixture and checks D-pad return navigation after selecting another node and selecting the original node again. Existing full focus reachability/QA66/QA70 tests must continue passing.
