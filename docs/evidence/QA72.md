## Proven source-level risk
`show_data()` silently replaces an invalid current selection with the first refreshed node. Its previous inspection or ping feedback remains in `_status_text`, so the next node can inherit an unrelated success or refusal. Refreshing during controller focus must also recover navigation.

## Change
Clear stale status and reset evidence scrolling when a refreshed catalog invalidates the selected node. Retain the existing focus recovery through `_restore_focus()`. Do not discard feedback for a still-valid selected node.

## Automated evidence
`test_QA72_refresh_rehomes_removed_selection_without_stale_feedback` rebuilds a real tablet with a reduced authoritative view; checks new selection, empty stale status and recovered focus.
