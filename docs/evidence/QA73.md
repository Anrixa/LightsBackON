# QA73 — Step analog-trigger zoom on press edges

- Date: 2026-11-06 UTC
- Starting main: `7c009810b814e7c05e03fede8787e9b2681e7129`
- Branch: `task/QA73-edge-triggered-tablet-zoom`
- Scope: controller input presentation only; no simulation, save, content version, Steam or publishing.

## Defect
`_input` called tablet zoom for every `InputEventJoypadMotion` sample above a trigger threshold. A physically held trigger produces repeated samples and could jump through multiple zoom levels instead of one step.

## Fix
Track each mapped trigger's press edge separately, rearm on its own release, and ignore unrelated stick-axis motion for the latch. Consume those tablet-modal trigger events. On a new opening the latches reset. Zoom remains requested-vs-effective fit-capped (QA68).

## Regression
`test_QA73_held_joypad_triggers_do_not_repeat_zoom_or_rearm_on_stick_motion` sends real joypad motion event objects for held trigger, unrelated stick, release/re-press and opposite trigger. Existing network focus/navigation tests remain.
