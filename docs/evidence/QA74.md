# QA74 — Scope tablet action feedback to its active Network tab

- Date: 2026-11-06 UTC
- Starting main: `6eb47ebd5b33681257ac5a30ee3710736fe52daa`
- Branch: `task/QA74-tablet-tab-feedback-scope`
- Scope: UI-only; no host authority, content revision, network protocol or save changes.

## Defect
The tablet ignores delayed replies when closed (QA70) or a different node is selected (QA67), but `on_reply()` still updates `_status_text` with Network-tab ping/inspection replies while the user reads Objectives. On returning, that stale reply can misleadingly appear as feedback for the current panel.

## Correction
Leaving Network clears its transient action banner; while Objectives is selected, Network replies cannot mutate the evidence status. Fresh accepted/refused replies remain visible when Network is active.

## Test
`test_QA74_objectives_tab_clears_and_ignores_network_action_feedback` covers accepted ping, tab switch, delayed refusal, return, and new accepted ping in a real tablet fixture.
