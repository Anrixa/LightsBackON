# QA76 — Retain tablet evidence position through same-node reflows

- Date: 2026-11-06 UTC
- Base: `57d473a192ffddf1cf84b0197a30c6e1ae3951a6`
- Branch: `task/QA76-evidence-scroll-reflow`
- Scope: presentation only; no new player intents, content or save-schema changes.

## Reproduced defect
The tablet deletes and recreates its ScrollContainer on show_data(), device changes and UI-scale changes. Even with the same selected node, a reader halfway through detailed meter evidence is reset to the heading. QA75 deliberately resets scroll only when selecting a *different* node; this change preserves that behavior.

## Fix and regression
Capture the evidence-pane vertical offset before rebuilding, restore it deferred after layout. Retain QA75's explicit zero on selection changes. `test_QA76_same_node_refresh_and_reflow_keep_evidence_reading_position` uses a 720p, 150% UI fixture with 70 evidence lines; asserts refresh retains 150 pixels and scale reflow remains scrolled.
