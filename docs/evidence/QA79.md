# QA79 — Latest tablet reply wins and request retention is bounded

- Date: 2026-11-06 UTC
- Starting main: `b8a8fd584906edac1d6120905b8702e9d6ff2a68`
- Branch: `task/QA79-latest-tablet-reply-wins`
- Scope: read-only Network tablet feedback. No grid authority, content revision, protocol, save or Steam change.

## Defect
QA78 filters replies from earlier tablet visits and previous selections. While the current visit remains on one node, several same-target ping/inspection requests can still be outstanding: an older refusal arriving after a newer acknowledgment may replace current feedback. Also, a transport that drops replies forever can grow the pending-request dictionary indefinitely.

## Correction
Record the latest sent sequence for each action+target within the current visible visit. Only that latest response may update feedback, and consume older pending replies without presenting them. Keep pending bookkeeping within 64 entries by dropping the oldest sequence. Closing, changing selection and leaving Network invalidate both sequence maps. Inspect and Ping remain independent.

## Regression
`test_QA79_newest_same_target_reply_wins_and_pending_requests_are_bounded`: two same-node pings, inverted reply order, later stale refusal, 72 missing responses, bounded pending cache and fresh success.
