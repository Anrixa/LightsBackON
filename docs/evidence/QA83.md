# QA83 — Tablet outbox lifecycle and session replacement

- Branch: `task/QA83-outbox-rebind-lifecycle`
- Defect: repeated `setup()` can register duplicate signal connections; switching outboxes leaves callbacks bound to a previous session.
- Correction: repeated binding to the same outbox is a no-op; replacement disconnects prior listeners, clears request/feedback state, then binds only the new outbox and its restricted gate.
- Regression: `test_QA83_rebinding_tablet_outbox_detaches_stale_session_and_avoids_duplicates` checks connection counts, stale replies, and fresh Ping outcome.
- Required: exact-head Linux/Windows CI, Windows export/smoke, resource probe, postmerge main CI. No claim of real controller, GPU/UX, Steam or publishing acceptance.
