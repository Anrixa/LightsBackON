# QA90 — Isolate tablet-originated outbox actions

- Baseline: `f256d00733affbdcdc42404d478f3efd3381b2eb` (QA89).
- Branch: `task/QA90-isolate-tablet-outbox-origin`.
- Defect: the Network tablet listened to all `IntentOutbox.sent` events while open, even if another caller generated the Ping/Inspect. Because they share an outbox, unrelated actions could clear the tablet feedback, be recorded as pending, and later render a result falsely as the tablet's action.
- Change: scope synchronous tablet gate dispatches via `_tablet_dispatch_active`. The handler observes only sends performed through the current tablet's own UI methods. All authority, payloads, sequence allocation, and outbox signals stay untouched.
- Regression: `test_QA90_shared_outbox_activity_does_not_replace_tablet_feedback` demonstrates an external same-target Ping does not clear, register, or replace tablet feedback; the tablet's own Inspect still works. QA67 correlated integration fixtures explicitly stage a scoped outbox `sent` event.
- CI gate: Linux/Windows `bash tools/run_tests.sh`; Windows release export and headless smoke; QA51 isolated lifetime probes; postmerge CI.
- No Steam operations or third-party assets. Not verified by CI: physical gamepad, GPU P95/memory, UX01/V09 human acceptance, F02/F06 two-PC Steam, publishing. Keep #51 OPEN.
