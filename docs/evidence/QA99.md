# QA99 — Validate read-only tablet objective list payload

- Baseline: `98f02c093871a629b71541c0216eebfb662b71ae` (QA98 merge).
- Defect: `_objective_list` indexed `status` and `text_key` on every Objective row and immediately constructed an icon state. Malformed rows, absent keys, or unsupported statuses could error during tab navigation after a snapshot refresh.
- Fix: `_valid_snapshot_objectives` requires dictionaries with string `status` and nonempty string `text_key`, and accepts only declared objective status chips. Reject invalid refreshes before changing any view data.
- Regression: `test_QA99_bad_objective_rows_do_not_replace_active_tablet` tests null rows, missing fields, invalid status, invalid type and blank text, plus valid tab navigation at 720p/150%; preserves last valid list, focus and pending Ping.
- Gates: exact-head Linux/Windows full tests, Windows export/smoke, QA51 resource probes, postmerge main CI.
- No physical GPU/controller, human play sessions, two-PC Steam, licensing or publishing acceptance. UI-only; no host/save/power/content mutation.
