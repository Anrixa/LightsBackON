# UX23 — guard long evidence against controller stick drift

## Root cause
`FocusScroll._process()` treated every nonzero right-stick value as intentional scrolling. Small analog noise can therefore slowly move the focused evidence/objective reading panel even when the player does not touch it.

## Code
- Ignore right-stick strength at or below 0.20 inside the focused scroll component.
- Keep deliberate stick scrolling, D-pad/keyboard step scrolling, user UI scale and inherited scroll bounds unchanged.
- This is a presentation-only deadzone, not a change to player camera or movement.

## Regression
`tests/integration/test_DS05_controller_reflow.gd` exercises a real focused, scrollable Network Tablet evidence pane using simulated 5% and 80% controller strengths.

## Gates and nonclaims
Requires final-source Linux/Windows full tests and export. Physical controller axes, device-calibrated drift, and real GPU performance/UX01 are still pending; headless simulated input does not satisfy them.
